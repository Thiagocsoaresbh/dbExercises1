# Exercícios de Banco de Dados (SQL / MySQL)

Material para quem está começando a aprender banco de dados relacional e SQL,
usando como exemplo o cenário de uma loja online (clientes, produtos,
pedidos e itens de pedido).

## Como usar (siga nesta ordem)

1. **[00_como_instalar.md](00_como_instalar.md)** — instala o MySQL na sua
   máquina (com opções pra quem nunca instalou nada de banco antes).
2. **[01_desafio_criar_banco.md](01_desafio_criar_banco.md)** — você modela e
   cria o banco com as próprias mãos: pensa nas tabelas, escreve os
   `CREATE TABLE` e digita os `INSERT` você mesmo, sem copiar código pronto.
3. **[02_solucao_criacao.sql](02_solucao_criacao.sql)** — solução do passo
   anterior, para conferir depois ou resetar o banco caso trave no meio do
   caminho.
4. **[03_exercicios_consultas.md](03_exercicios_consultas.md)** — exercícios
   de consulta (`SELECT`, `WHERE`, `JOIN`, subconsultas, etc.) sobre o banco
   que você acabou de montar.

O gabarito dos exercícios de consulta é material do professor e não fica
neste repositório (fica só na máquina local de quem está aplicando o curso).

## Requisitos

MySQL ou MariaDB. Veja as opções de instalação em
[00_como_instalar.md](00_como_instalar.md) (XAMPP, MySQL Workbench, ou um
site sem instalar nada, para testes rápidos).
